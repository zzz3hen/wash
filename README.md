# 宿洗通 DormWash - 宿舍洗衣機即時使用看板

> 大學「自然科學與人工智慧」課程期末專題作品  
> 專題目標：解決宿舍洗衣機大排長龍、洗完無人取出佔位、需頻繁跑洗衣間確認空位的痛點。

---

## 🌟 核心特色與功能

1. **機台狀態即時看板**
   - 🟢 **空閒有位**：顯示各機台位置（如 2F/3F/4F 洗衣機或烘衣機），點擊即可一鍵啟用。
   - 🟡 **洗滌運轉中**：直覺動態旋轉滾筒動畫、進度條與精準倒數計時（分:秒），並標記預計完成時間。
   - 🔔 **洗滌完畢・待取衣**：倒數結束後機台發光提醒，播放 Web Audio 提示音效與發送瀏覽器桌面通知。
   - ✨ **結束使用釋放**：拿完衣服後點選「拿完衣服・結束使用」，機台即時恢復為「空閒有位」，供下一位住宿生使用。
   - 🔧 **故障維修中**：設備保養或報修時呈現停用標籤，避免同學誤投硬幣。

2. **跨分頁與跨視窗即時同調 (BroadcastChannel + LocalStorage)**
   - 模擬多人真實使用情境：在電腦開啟兩個視窗或分頁，一邊啟動洗衣機，另一邊會「即時零延遲」同步更新倒數與狀態！

3. **示範快進模式 (Demo Fast-Forward Mode)**
   - 課堂簡報與現場 Demo 神器：一般洗滌需等待 30 分鐘，開啟右上角「⏱️ 示範快進模式」後，倒數縮短為 30 秒，方便現場評審或同學即時驗證洗畢音效與狀態轉換。

4. **機台資料管理面板 (CRUD Panel)**
   - 符合期末評量規準**「管理／資料功能」**加分項（+1～10分）：
     - **Create（新增）**：新增洗衣機或烘衣機至指定樓層。
     - **Read（查看）**：以表格檢視全宿機台運行狀態。
     - **Update（編輯）**：一鍵切換設備為「報修中」或「恢復正常」。
     - **Delete（刪除）**：刪除廢棄或停用設備。

5. **音效與提醒**
   - 採用瀏覽器原生 **Web Audio API** 合成清脆提示音，免載入外部大型音檔。
   - 支援 **Web Notification API**，即使切換到其他分頁也能收到洗畢提醒。

## 🚀 本地啟動與試用方式

### 方式一：直接用瀏覽器開啟（最簡單）
直接以瀏覽器（Chrome, Edge, Safari）雙擊打開 `index.html` 即可立即試用！

### 方式二：使用本機 HTTP 伺服器
在終端機中切換到本專案目錄：
```bash
cd /Users/zhen/.gemini/antigravity/scratch/dorm-laundry-tracker
```
啟動內建伺服器（macOS 內建 Ruby）：
```bash
ruby -run -e httpd . -p 3000
```
接著在瀏覽器打開：`http://localhost:3000`

### 💡 雙分頁互動測試（推薦試用）
1. 在瀏覽器中打開兩個分頁（分頁 A 與分頁 B）並排在螢幕左右。
2. 在分頁 A 打開「⏱️ 示範快進模式」，點擊 `#1 洗衣機` 的「選取並開始使用」。
3. 觀察分頁 B：**立即看到 #1 洗衣機變為黃色運轉中，並同步倒數 30 秒！**
4. 倒數 30 秒結束，聽取提示音，卡片變為「🔔 洗滌完畢・待取衣」。
5. 在分頁 A 點擊「拿完衣服・結束使用」，分頁 B **立刻恢復為綠色「空閒有位」**！

## 🌐 部署上線指南 (Vercel)

本專案為零依賴的現代靜態 Web 應用，部署至 Vercel 極度快速且永不失敗：

1. 將本專案推送到個人的公開 GitHub 專案庫（Public Repository）。
2. 前往 [Vercel 官網](https://vercel.com) 登入。
3. 點選 **Add New...** → **Project**。
4. 匯入該 GitHub 專案，Framework Preset 選擇 **Other**，Root Directory 保持 `./`。
5. 點擊 **Deploy**，約 15 秒後即可取得 `https://your-project.vercel.app` 上線網址。
